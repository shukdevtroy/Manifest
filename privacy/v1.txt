  <h1>Manifest Privacy Policy</h1>
  <p class="meta">Last updated: October 4, 2026</p>

  <p>Manifest is a Chrome extension that adds AI code suggestions and code actions (Explain, Comment, Fix, Docstring) to the GitHub web editor. This page explains what data it handles and why.</p>

  <h2>What Manifest handles</h2>
  <ul>
    <li><strong>Code you are editing or select.</strong> When you pause typing or run an action, the surrounding code (or your selection, up to 10,000 characters) is sent to Groq to generate a response.</li>
    <li><strong>Your Groq API key.</strong> You enter it in the extension. It is stored locally in your browser.</li>
    <li><strong>Your GitHub sign-in token.</strong> You sign in with GitHub's device flow. The resulting token is stored locally in your browser.</li>
    <li><strong>Settings.</strong> Preferences such as turning suggestions on or off are stored locally in your browser.</li>
  </ul>

  <h2>Where your data goes</h2>
  <p>Manifest sends requests directly from your browser to Groq (<code>api.groq.com</code>) using your own API key, and to GitHub for sign-in. We do not run a server that receives your code, your keys or your tokens. Groq processes the code it receives under its own terms and privacy policy, which you can read at <a href="https://groq.com/privacy-policy/">groq.com/privacy-policy</a>.</p>

  <h2>What we do not do</h2>
  <ul>
    <li>We do not collect, store or have access to your code, API key or GitHub token.</li>
    <li>We do not sell or share user data with third parties.</li>
    <li>We do not use your data for advertising, creditworthiness or any purpose unrelated to the extension's single purpose.</li>
    <li>We do not run analytics or tracking.</li>
    <li>We do not load or run remotely hosted code. All extension code is bundled in the package.</li>
  </ul>

  <h2>Permissions</h2>
  <ul>
    <li><strong>github.com:</strong> to read the code being edited and show suggestions and panels in the GitHub editor.</li>
    <li><strong>api.groq.com:</strong> to generate AI responses with your API key.</li>
    <li><strong>storage:</strong> to keep your settings, key and token locally.</li>
    <li><strong>contextMenus:</strong> to add the right-click Manifest menu on selected code.</li>
  </ul>

  <h2>Your control</h2>
  <p>Stored data stays in your browser. You can remove your key and token at any time by signing out in the extension, clearing its data, or uninstalling it. You can revoke GitHub access in your GitHub account settings and delete your key at console.groq.com/keys.</p>

  <h2>Children</h2>
  <p>Manifest is a developer tool and is not directed at children under 13.</p>

  <h2>Changes</h2>
  <p>If this policy changes, the new version will be posted on this page with an updated date.</p>

  <h2>Contact</h2>
  <p>Questions about this policy: open an issue on the <a href="https://github.com/shukdevtroy/Manifest/issues">Manifest repository</a>.</p>

  <p class="meta" style="margin-top:2.5rem">Manifest is an independent tool and is not affiliated with or endorsed by GitHub or Groq.</p>
