Manifest Pro Privacy Policy

Last updated: October 6, 2026

Manifest Pro ("the extension") is a browser extension that provides AI code suggestions and code actions in GitHub's web editor. This policy explains what data the extension handles. In short: there is no Manifest Pro server, and the developer does not collect, receive or store any of your data.

Data stored on your device

The extension saves the following in your browser's local extension storage. It never leaves your device except as described in the next sections.

  • Your GitHub username, avatar URL and sign-in token.
  • The API keys you enter for Groq, Hugging Face and OpenRouter.
  • Your settings, such as the chosen provider and the on/off toggles.

Logging out removes your sign-in and API keys from the extension. You can also remove individual keys under Manage API keys, or uninstall the extension to delete everything.

Data sent to AI providers

When you type in the GitHub editor and a suggestion is requested, or when you run an action (Explain, Add comments, Fix bug, Write docstring), the extension sends the following to the AI provider you selected, using your own API key:

  • The file name and the code around your cursor (for suggestions), or the code you selected (for actions).

Only the providers for which you entered a key are contacted. If you enable auto-switch, the request may be sent to your next configured provider when the first one is rate-limited. Providers handle data under their own policies:

  • Groq: groq.com/privacy-policy
  • Hugging Face: huggingface.co/privacy
  • OpenRouter: openrouter.ai/privacy

Please do not use the extension on code you are not allowed to share with these providers. You can turn suggestions off at any time with the "Enable suggestions" switch.

GitHub sign-in

The extension signs you in with GitHub's OAuth device flow and requests only the read:user scope. After sign-in it makes one request to the GitHub API to read your username and avatar for display. The extension does not read your repositories through the GitHub API. It only reads and edits text on the GitHub web page you are using, when you trigger a suggestion or action.

What we do not do

  • No analytics, telemetry, tracking or advertising.
  • No selling or sharing of data with third parties.
  • No data collected by the developer.
  • No remote code: all code ships in the extension package.

Permissions

  • storage: save your settings, sign-in and keys locally.
  • contextMenus: add the right-click "Manifest Pro" menu.
  • github.com and api.github.com: run in GitHub's editor and sign you in.
  • api.groq.com, router.huggingface.co, openrouter.ai: contact the AI provider you chose.

Children

The extension is intended for developers and is not directed at children under 13.
