Everything you reach for, without leaving the page

Built for people who edit code on GitHub and want help where they already are.

Suggestions as ghost text

Pause for a second and grey text streams in as the model writes it. Tab takes all of it, Ctrl+Right takes one word, Esc waves it away.

Up to five alternatives

Not the idea you wanted? Alt+] cycles options and generates a genuinely different one when you run out.

Explain, in a side panel

Select code and get a streamed explanation next to it. Works on read-only file views too.

Comment, Fix, Docstring

Each one shows a diff first. Apply replaces your selection; Copy keeps the editor untouched. You stay in charge.

Three providers, one switch

Pick Groq, Hugging Face or OpenRouter in the popup, or let Manifest Pro fail over on its own when a limit is hit.

Keys stay in your browser

Your API keys are stored locally and sent only to the provider they belong to. GitHub sign-in uses the secure device flow.

When one free limit runs out, the next one is already warm

Free tiers are generous but finite. Manifest Pro treats that as a normal event instead of an error you have to wait out.

You pause typing→Groq→limit reached→Hugging Face→OpenRouter→suggestion appears

A provider that just hit its limit is skipped for about a minute, so suggestions stay quick. Prefer another provider first? Select it in the popup and the others become the backups.

Running in a few minutes

Manifest Pro comes as two extensions, one for Chrome and one for Microsoft Edge. Pick your browser below.

  1. Install the extension for your browser
    Chrome Web StoreOpen Manifest Pro on the Chrome Web Store, click Add to Chrome, then Add extension. Refresh any open GitHub tabs. Microsoft Edge Add-onsOpen Manifest Pro on Microsoft Edge Add-ons, click Get, then Add extension. Refresh any open GitHub tabs. Chrome and Edge each have their own extension, so install the one that matches your browser. Other Chromium browsers such as Brave can use the Chrome version.
  2. Sign in with GitHubClick the Manifest Pro icon, sign in, and enter the code at github.com/login/device.
  3. Add at least one keyGroq key from console.groq.com/keys (starts with gsk_). Hugging Face token from huggingface.co/settings/tokens: make it fine-grained and enable "Make calls to Inference Providers". OpenRouter key from openrouter.ai/settings/keys. One key is enough; add more for automatic switching.
  4. Edit a file on GitHubClick the pencil icon, type, and pause for about a second. Ghost text appears. Press Tab to accept it.

Hands stay on the keys

On Mac, read Ctrl as Cmd and Alt as Option. Action shortcuts can be changed at chrome://extensions/shortcuts in Chrome or edge://extensions/shortcuts in Edge.

Good to know


Does it cost anything?
Manifest Pro is free. Groq, Hugging Face and OpenRouter all offer free options, so check their sites for current limits. Hugging Face's free tier is a monthly credit allowance and OpenRouter's free models have request limits, so they make strong backups rather than bottomless ones.


Do I need all the keys?
No. One key is enough. With two or more, you get the automatic switch and a choice of primary provider.


Where does it work?
On github.com, mainly the file edit page. Explain also works on read-only file views. Apply only works in the editor.


Suggestions aren't showing up.
Refresh your GitHub tab after installing or reloading, confirm "Enable suggestions" is on in the popup, and check that at least one key is saved. Alt+] triggers a suggestion on demand.


Is my code sent anywhere?
Only the surrounding code or your selection is sent, directly from your browser to the provider you chose. There is no Manifest Pro server in between.
