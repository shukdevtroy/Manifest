Features
Everything you need, nothing you don't
Built for people who edit code on GitHub and want AI help without leaving the page.




⚡
Streaming suggestions
Ghost text appears word by word as Groq generates it, usually within a second of you pausing.


🧩
Accept your way
Take the whole suggestion with Tab, or just the next word with Ctrl+→ for full control.


🔀
Up to 5 alternatives
Not feeling the first idea? Cycle options, and Manifest generates a fresh one when needed.


💡
Explain code
Select any code and get a clear explanation streamed into a side panel. Works on read-only views too.

Fix, Comment, Docstring

🔒
Private by design
Your Groq API key is stored locally in your browser. Sign in with GitHub's secure device flow.





How to use
Up and running in a few minutes


    

  1. Download the Manifest zipGet Manifest.zip from the Google Drive link.
    2. 

  2. Unzip it with the passwordRight-click the zip and extract it. Opening any file inside asks for a password, which you get from the developer. On Windows use 7-Zip or WinRAR (the built-in extractor doesn't support this encryption). You'll get a folder named Manifest.
    3. 

  3. Load it in ChromeOpen chrome://extensions, turn on Developer mode, click Load unpacked, then select the extracted Manifest folder. Refresh any open GitHub tabs.
    4. 

  4. Sign in with GitHubClick the Manifest icon, choose Sign in with GitHub, and enter the code shown at github.com/login/device.
    5. 

  5. Add your Groq API keyCreate a free key at console.groq.com/keys, paste it (starts with gsk_) and hit Save.
    6. 

  6. Open a file in the GitHub editorClick the pencil icon on any file, start typing and pause for about a second. Grey ghost text appears.
    7. 

  7. Accept, cycle or dismissUse Tab, Ctrl+→, Alt+] and Esc. Select code and right-click → Manifest, or use the action shortcuts below.
    8.

FAQ
Good to know


Do I need to pay for anything?
Manifest itself is free. You need a Groq API key, and Groq offers a free tier. Check Groq's site for current limits.


Where does it work?
On github.com, mainly the file edit page. Explain also works on read-only file views.


Suggestions aren't showing up. What now?
Refresh your GitHub tab after installing or reloading the extension, make sure "Enable suggestions" is on in the popup, and confirm your Groq key is saved. Press Alt+] to trigger one manually.


Is my key safe?
Your Groq API key is stored locally in your browser and used to call Groq directly.


Which model does it use?
GPT-OSS 120B (openai/gpt-oss-120b) served by Groq.
